### 3. Context Retention
Gemma 3 4B performed best at context retention (80% on medium difficulty), suggesting better multi-turn capability.

### 4. Formatting Constraints
All models struggle with strict formatting constraints (word count, sentence count, exact JSON structure). This is a common limitation of smaller local models.

### 5. Llama 3.1 8B Failure
Llama 3.1 8B failed completely due to Ollama timeout issues. This may be related to:
- Ollama 0.32.6 compatibility
- Model quantization (Q4_K_M)
- GPU memory fragmentation after running other models

## Recommendations

1. **For speed-critical applications**: Use Gemma 3 4B
